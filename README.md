# 📌 Project Overview

**SkillSphere** is a modern and responsive online learning platform where users can explore skill-based courses, access structured learning content, and improve their technology skills through project-based learning.

The platform provides courses in areas like Web Development, Design, Marketing, and other technology programs with an interactive learning experience.


### Main Features:

- Interactive course browsing
- Dynamic curriculum modules
- Secure authentication
- Personalized student dashboard
- Course progress tracking
- Responsive user interface

# 🔐 Environment Variables


Create a `.env.local` file in the project root:


```env
# Application URL

NEXT_PUBLIC_BASE_URL=https://skillsphere-psi-six.vercel.app
BETTER_AUTH_URL=https://skillsphere-psi-six.vercel.app


# MongoDB

MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/skillsphere


# Better Auth

BETTER_AUTH_SECRET=your_secret_key


# Google OAuth

GOOGLE_CLIENT_ID=your_google_client_id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your_google_client_secret
